## 試聴・再生タイミングの案

以下は実装前の提案であり、実際の音量・長さは音源取得後に調整する。

- 最初の比較対象はWish5の通常版とHarpOnly。公式ページには両方とループ版がある。読み上げとの重なりを考慮し、HarpOnlyも比較するが原作と同じ版とは断定しない。
- BGMはまず原作の用途に合わせ、扉と二色の紙を考える場面に限定して比較する。調理音・会話・会社設立まで常時流すかは試聴後に判断する。
- 決定音は材料を選んだ操作で一度だけ。描画更新、設定開閉、保存復元では再発火させない。
- 調理音は実際の工程に合わせ、工程切り替えとともに止める。完成料理を待つ画面で無制限に鳴らし続けない。火を止めたカルボナーラ仕上げ等で焼く音を鳴らさない。
- 成功音は注文の料理が完成した公開時、別の料理にはひらめき音を比較。謎の成功音は正解確定時に一度だけ。扉の物理音と重ねる場合は音量と順序を確認する。
- 導入・結末のジングルは一度だけ。保存からの復元や文章送りのたびには再生しない。
- BGMと効果音は別のオン／オフと音量にする。初回はオフで、ユーザー操作で有効化する。Gemini TTSの一括合成は後工程として分離する。
- 設定・履歴・タブ非表示で中断する既存基盤を利用し、復帰で古い効果音を再生しない。欠損・再生拒否でも進行を止めない。

### 取得時の接続問題（解消済み）

2026-11-07、実行環境からWish5の公式ページを取得するHTTP要求が403となった。Web調査ツールでは公式本文と上記の配布リンクを確認できたが、音声バイナリの保存には対応していない。音源ファイルはまだ取得できておらず、試聴・ラウドネス計測・ハッシュ取得・ゲーム組み込みは未実施。HTMLエラーを音源として保存したり、他者の転載音源で代用したりしない。

その後の診断で `CONNECT tunnel failed, response 403` を確認。サイトのHTTP応答前に環境プロキシが拒否しており、環境のネットワークポリシーは制限モードで3配布元とも許可リストに未登録だった。取得再開には環境設定で `peritune.com`・`pocket-se.info`・`taira-komori.net` を許可する必要がある。別ドメインの転載やプロキシ回避で代替しない。

### 取得ツールの使い方

候補一覧は `content/audio-sources.json`。これは制作資料で、ゲームの音声設定には自動で反映しない。音声の取得・取り込みには `ffprobe` が必要。

```sh
# 一覧または個別の出典を表示するだけ。通信・ダウンロードしない
python3 scripts/prepare-audio.py
python3 scripts/prepare-audio.py success

# 接続許可後に公式のMP3を1件取得
python3 scripts/prepare-audio.py success --download

# 公式から手元に取得済みの場合は取り込みも可能
python3 scripts/prepare-audio.py success --import-file /absolute/path/kirakirarin.mp3
```

ファイルはGitの対象外の `.audio-cache/<ID>.mp3`、取得日時・出典・配布先・形式・長さ・SHA-256は同じディレクトリの `<ID>.json` に保存する。実体がMP3でない応答は保存せず、既存の原音・記録は上書きしない。取り込んだだけでは出典や原作との一致を検証した扱いにせず、`listened: false`・`adopted: false` で記録する。

Wish5は公式ページのHTMLから通常版とHarpOnlyのMP3取得先を確認して登録済み。公式の案内どおり配布URLのHTTPをHTTPSに変更して取得した。ループ版ZIPは未取得。On-Jin音源は今回の候補登録・取得対象に含めていない。

取得スクリプトはネットワークなしで、合成した検証用MP3とHTMLエラーを使い、音声の実体検証・不正応答の拒否・ハッシュ記録・上書き防止・一時ファイルの片付けを確認した。実音源での試聴・音量調整は接続許可後の作業。

採用時には各音を公式の配布ページと対応づけ、作者・ページURL・取得日・適用条件・元ファイル名・ハッシュ・加工内容を記録する。ゲーム内にクレジットの入口を設け、実際に採用した素材だけを掲載する。

GitHubリポジトリは公開のため、素材単体の再配布が禁止された音源をそのままコミットしない。ゲームへの組み込み許可を、素材として自由に再配布できる許可とは扱わない。コードのライセンスを第三者音源へ適用せず、必要なら公開ソースには取得手順と条件を残し、配信物への組み込みを分ける。

## 2026-11-07のゲーム組み込み

暫定採用はWish5 (HarpOnly)とポケットサウンド5音（決定・成功・別料理・開始・結末）。原音は保持し、`scripts/build-audio.py` がハッシュ照合後、減衰・必要な短縮・フェード・再エンコードを行う。生成物は `dist/audio/` の6音源と `sources.json`。素材単体の公開を避け、GitHubには生成手順と出典・加工記録のみを保存し、既存の所有者限定サイトのゲーム配信へ同梱する。

BGMは扉・部屋・二色の紙を考える場面に限定。通常版BGM、調理の実音、オーブン・扉・ダイヤルの物理音は未採用。音色の最終的な聴取評価とスマートフォン実機の音量調整は引き続き必要。

設定画面からBGM・効果音を独立して有効化し、各音量を変更できる。初回はオフ。選択は別キー `cinderella-audio-v1` に保存し、ストーリー保存の形式は変えない。成功音は操作で進んだときだけ鳴らし、描画更新・保存復元では鳴らさない。クレジットには採用分の配布ページと、Wish5の作者・CC BY 4.0・変更内容を表示する。
