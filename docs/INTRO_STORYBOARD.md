# 導入：シンデレラを助けたくなるまで

更新：2026-11-01（日本時間）。衣装はユーザーが選んだ②（三角の頭巾）。背景を固定し、導入は全てボタン操作で進む。

## お願い画像の修正

`help-characters.png` は、ユーザーに提示した修正案を「実装に反映して」の指示で採用。後ろの小さな結い髪へ戻し、ボウル・混ぜる道具・本台を削除した。採用の基準は [衣装比較の中央②](references/costume-comparison.png)。導入の調理・本を隠すアトラスは維持。料理完成後は同じ採用画像を土台に、お姉さんの顔だけ新しい2表情を重ねる。旧試食コマは読み込み失敗時の代替に残す。

## 画面と進行

最初の画面は同じ文章欄に1文ずつ追加する。次のクリックまで文章・絵ともに止める。動きを減らす設定でも文章の区切りとクリック回数は変えない。

| ボタンを押す前の文 | 絵 | 次のボタン操作 |
| --- | --- | --- |
| 料理が得意なシンデレラ。 | シンデレラが料理の本を見ながらボウルを混ぜる | 「つづきを読む」で2つ目の文を追加 |
| しかし、おねえさんがいじわるをして、 | 姉が本を持ち去る途中 | 「つづきを読む」で3つ目の文を追加 |
| 大切な料理の本を隠してしまいました。 | 姉が本を隠した後 | 「つづきを読む」で注文へ |
| それなのに、お姉さんは料理を頼んできます。／姉「シンデレラ、カレーを作っておいてね。」 | 姉が注文する | 「つづきを読む」でお願いへ |
| シンデレラ「材料さえ分かれば、おいしいカレーが作れるのに！」／「シンデレラのために、カレーの材料を選んであげますか？」 | シンデレラがこちらへ手を差し出す | 「はい」で初めて材料選びへ。「いいえ」は休止し、お願いへ戻れる |

導入の自動進行タイマーは撤去。前の文をDOMに残し、新しく加えた文だけを読み上げる。読み上げが終わっても絵や文章は進めない。「私の名前はシンデレラ」は省略する。

## 原作との照合

保存コード `confirmQuiz0` の日本語コメントにある、シンデレラの台詞→「シンデレラのために、${target}の材料を選んであげますか？」→Yes／Noの応答待ち、を保持する。導入の区切りと手動操作はウェブ版用の演出。

## 固定背景と透過素材

- `dist/assets/kitchen-background.png`：人物・本・ボウルを含まない、1枚の固定背景。
- `dist/assets/help-characters.png`：プレイヤーと目を合わせ、手前に手を差し出すお願いの人物の透過画像（ボウル・本台なし）。お願いと材料選びではこの画像を使用する。
- `dist/assets/sister-delighted.png`／`sister-pleased.png`：注文どおりの満面の笑顔と、違う料理でも目を開けて頬を染める笑顔。顔だけCSSマスクで採用画像へ重ね、髪・服・体・シンデレラを固定。
- `dist/assets/intro-characters.png`：人物と本・道具を含む透過画像。2列×3行。調理、本を持ち去る途中、本を隠した後、こちらへのお願い、試食の満面の笑顔、別の料理を喜ぶ顔。

背景の上に透過素材を重ね、必要な人物のコマだけを表示する。3枚目以降の胴体がテーブルの奥辺につながるよう、後半の人物レイヤーだけをキャンバスの3%下へ調整。最初の調理・本を取る場面の位置と、背景の位置・倍率は変えない。背景のsrcと配置は切り替えない。人物・本の独立した連続変形アニメーションではなく、透過コマの段階切り替え。人物のポーズ自体は意図した変化として残る。

背景と人物は同じ固定キャンバスを共有する。デスクトップの絵の高さも400pxに固定し、文章量が増えることで背景まで拡大縮小されることを防ぐ。スマートフォンでは3:2。画像取得に失敗しても文章と問いかけは進行可能。

背景込みの旧素材 `intro-scenes.png`、`intro-cooking.png` と旧表情は記録として残し、現在の画面では読み込まない。

## 材料選びとの接続

3組の食材ペアの順序と左右を挑戦ごとにシャッフルし、設定・履歴の開閉で入れ替えない。料理判定は選択順に依存させない。

しらたきの台詞は豚肉／しらたきのペア、ちくわぶを見る地の文はカレールー／ちくわぶのペアに紐付ける。じゃがいも／たまごには追加の吹き出しを出さない。他の料理にも一律に天然な言動を追加しない。
