## 現在地

一周目は最初から結末までプレイ可能。台所の三料理章、城の外観・扉の開閉・魔法の部屋、操作できる四桁のダイアル錠まで画像化・配信済み。ユーザーはダイアル反映後に「OK」と返答し、別セッションで残りの制作を続けるための引き継ぎを依頼した。

| 完了した範囲 | 保持する状態 |
| --- | --- |
| シンデレラ・姉・母親・王子 | 採用済み人物と顔の表情。顔だけを重ね、人物全体を表情ごとに再生成しない |
| 台所・通常料理 | 背景、食材16種、通常の完成16料理、料理別器具。完成皿は公開操作後だけ表示 |
| 城の外観 | `dist/assets/castle-exterior.png` |
| 閉扉・開扉 | `castle-door-closed.png` / `castle-door-open.png`。同じ構図で切り替える |
| 魔法の部屋 | `magic-room.png`。背景を固定し、二色の紙は独立したDOMで一枚ずつ消す |
| 扉の札 | `doorInscription()` とDOMで表示。現行一周目は「おえかき」。将来別の文字になるので画像に焼き込まない |
| 四桁の錠前 | 金の枠と数字はDOM。扉の数字・下の上下ダイアル・直接入力を同期。初期0000、0〜9を循環、全角入力対応。ヒント・誤答・保存再開で保持し、開扉後は非表示 |

**ユーザーの明示指定：十字架を使わない。** 宗教的な意味があるため。初期案の窓・旗・装飾は修正し、葉・花・曲線を使った。窓の交差する桟も除いた最終画像がリポジトリにある。旧生成案へ戻さない。

## 次の制作対象

残っているのは**完成パンプキンプリン、王子の感動、会社設立とお取り寄せの後日談、完了画面の画像仕上げ**。プリンはまだ絵文字、終幕は会社の紋章で仮表示している。完成素材として扱わない。

まず完成プリンと終幕の構図案を示し、見た目を確認してから順に反映する。プリンの器・盛り付け・大きさ、城での人物の配置、会社と後日談に何枚使うかは未決定。無断で全場面を量産したり、二周目以降・周回・図鑑・経営システムを追加しない。

| phase | 現状と仕上げの注意 |
| --- | --- |
| `final-ready` | 紙が両方消え、物語で材料を明示する。完成プリンは表示しない |
| `final-cooking` | 魔法のオーブンに淡い光。通常器具や完成皿を重ねない。「できた料理を見る」は手動 |
| `final-result` | 公開後に初めてプリンを表示。王子の感動と協力の依頼。休止・保存再開を維持 |
| `ending` | `storyStep` 0＝王子の出資、1＝会社の繁盛、2＝姉と母のお取り寄せ。現状は全段階で同じ会社の紋章＋仮プリン |
| `complete` | おしまいとお礼。現状は会社の紋章、プリンは非表示 |

人物と料理は必要に応じて独立素材にする。城で人物を出すには配置を設計し、採用人物を再利用する。`showPrince()` の条件だけを広げて台所背景を城へ出さない。料理の接地面も先に設計し、画面の下端へ浮かせて置かない。

## 守る動作と素材

- シンデレラは `help-characters.png` が基準。結い髪、小さな生成りの三角の頭巾、青いリボン、普段着とエプロン。同ファイルには姉も含むので、そのまま城へ貼らない。
- 王子は `prince.png` と顔用の `prince-delighted.png` / `prince-pleased.png` が採用済み。人物・顔マスクの扱いは現行コードと [王子の記録](references/prince-request-preview.md) を参照。
- 台詞、料理と謎の判定、意味のまとまりで手動進行するノベルUI、選択直後300msとダブルクリックのガードを維持する。
- 保存キー `cinderella-first-journey-v1`、version 1、`readLayout:2` を維持。phase・会話位置・回答下書き・紙の解決・履歴を画像追加のためにリセットしない。
- 紙を解く前の背景に、かぼちゃ・たまご・砂糖・完成プリンを描かない。扉の答えやヒントを画像で先に見せない。現在の判定を正本とし、二周目の謎を混ぜない。
- 城の札と数字、二色の紙はDOMのまま。文字や操作を画像へ焼き込まない。
- 3:2の背景と重ねる要素は `--scene-width` / `--scene-height` の座標を共有。料理は `#table-plane` 内に置き、狭幅・低い画面・幅の往復を確認する。
- 画像失敗時も文章・入力・操作で最後まで進める。
