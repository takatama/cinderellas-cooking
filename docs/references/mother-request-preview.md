# 母親の依頼場面：構図確認案

作成：2026-11-01（日本時間）。取得した `codex/first-journey` の HEAD は `25bb6da`。

[確認用画像](mother-request-preview.png)。ユーザーの「はい」で構図・母親像を採用。母親を透過素材にしてアプリへ反映した。

`help-characters.png` と `kitchen-background.png` を参照し、母親は茶色のまとめ髪、紫の服、真珠の耳飾りとブローチで制作した。少し気取った依頼の表情。テーブルには完成料理・材料・本・ボウルを描いていない。

これは構図と人物像の確認用の生成画像。シンデレラや背景は元画像と画素単位で一致しない。実装はこの背景込み画像を使わず、既存の `help-characters.png` の左50.5%をCSSで切り出し、母親の独立した透過レイヤー `mother.png` を重ねた。シンデレラの画素、背景、`table-plane`、台詞・判定・保存は保持した。

`mother-delighted.png` はハンバーグを味わい目を閉じる満足顔、`mother-pleased.png` は別の料理を味わい目を開けた控えめな笑み。顔の楕円マスク（元画像の69%／33%、半径8%／12%）だけを通常原画に重ねる。画像は全て1536×1024。位置は背景キャンバスに対して左16%・上4.5%・幅78%・高さ75.5%。母親の画像が取得できない場合は従来の紋章へ戻り、表情だけ取得できない場合は通常顔を維持する。

[母親の六料理の確認案](mother-dishes-preview.png)は未採用。上段左からハンバーグ・メンチカツ・ロールキャベツ、下段左から野菜炒め・コロッケ・ポテトサラダ。料理と新食材はまだ仮表示のまま。料理案を確認してから個別透過素材を作り、低い目線・余白・接地位置を既存のカレーに合わせる。
