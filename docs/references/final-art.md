# 完成プリンと終幕の画像仕上げ

2026-11-01（日本時間）。[六場面の構図案](final-art-composition-preview.png)を提示し、ユーザーの「全部OK。進めて」で採用した。

## 素材と場面

| 素材 | 用途 |
| --- | --- |
| `dist/assets/pumpkin-pudding.png` | 独立した透過プリン。低い目線、金縁の生成りの皿、カラメルをまとった一人分 |
| `dist/assets/tasting-table.png` | 城の試食・出資の場面だけに重ねる透過テーブル |
| `dist/assets/company-workshop.png` | 会社の繁盛と最後のお礼に共用する工房背景。人物・プリンは含まない |
| `dist/assets/mail-order-home.png` | 姉と母の家の食卓。開封した箱とふたを描き、人物とプリンは含まない |
| `dist/assets/mail-order-epilogue.png` | お取り寄せ専用画。姉は箱を開け、母はスプーンを持つ。背景・人物・箱を一枚で整合させ、プリンは含まない |

`final-result` は `tasting`、`ending` の `storyStep` 0/1/2 は `investment` / `company` / `mail-order`、`complete` は `thanks` に切り替える。魔法の部屋は既存の `magic-room.png` をそのまま使う。`room` から `final-cooking` までは人物・新テーブル・完成プリンを表示しない。プリンは既存の「できた料理を見る」後の `final-result` と `ending` だけ。

シンデレラは `help-characters.png` の採用画素をCSSで切り出す。シンデレラ側の右端に入り込む姉の指先は、終幕専用のポリゴンクリップで除外。王子は感動と会社で `prince-delighted.png`、出資で `prince-pleased.png`。表情だけを既存と同じ楕円マスクで重ね、髪・衣装・体・ポーズは変えない。完了はシンデレラだけを中央に置き、プリンは非表示。

ユーザーの追加指示で、お取り寄せには新しい専用画を採用。既存の姉と母を参照し、同じ髪・衣装・人物の特徴を保ち、姉は箱のふたを持ち、母はスプーンを口元へ運ぶ異なるポーズにする。母の頭と体格を姉と同じ自然な縮尺にし、開封した箱を手前へ置いた。専用画が読めないときだけ、姉は`help-characters.png`と`sister-pleased.png`、母は`mother.png`と`mother-pleased.png`へ戻す。旧画像は置換・削除していない。

工房と完了では、元の`company-workshop.png`をもう一枚同じ座標に置き、箱とカウンターのシルエットだけをCSSで切り出して人物より手前に重ねる。人物で箱の上部を隠さない。お取り寄せ専用画が読めない場合にも`mail-order-home.png`の箱を同様に重ね、専用画が読めた場合は旧人物と箱の重ね絵を隠して二重表示を防ぐ。

3:2の背景と人物は `--scene-width` / `--scene-height` の座標を共用。人物の下端はテーブルの奥に隠す。人物の横広がりの指摘を受け、人物枠も元画像と同じ `aspect-ratio:3/2`、`height:auto`、`object-fit:contain` に修正。シンデレラ・姉は幅84%、王子・母は82%で縦横均等に縮小する。完了のシンデレラは左29.5%。表情マスクの原画像内座標は維持。プリンは既存の `#table-plane` 内で幅34%、左33%、下7.5%。新背景は十字架を使わず、交差桟のない窓と葉・花の意匠にした。採用済みの既存素材は置換していない。

札・数字・二色の紙は既存DOMのまま。台詞・判定・手動のノベル操作・300msガード・保存キー/version/readLayoutは変更していない。新素材が読めない場合は、背景の説明・通常顔・料理名・簡易テーブルで補い、文章と操作は継続する。
